`lyssna.png` comes from [Stormanzanii/Lyssna](https://github.com/Stormanzanii/Lyssna/blob/main/assets/lyssna.png).

The creator gave iPixelGalaxy permission to use the logo for Lyssna Lyrics. The original PNG is kept as a reference. The extension uses the exact `Mic2` / `MicVocal` SVG from Lyssna's Lyrics toolbar button (`frontend/App.tsx`), without the circular background. Its paths, circle, 24×24 view box, and 2px stroke match the UI icon. The inline version follows the surrounding icon color.
